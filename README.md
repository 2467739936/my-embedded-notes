# my-embedded-notes

给未来自己看的嵌入式学习笔记。目标岗位：**嵌入式软件（MCU 固件方向）**。

## 这个库怎么用

- **按主题分目录**，文件名格式：`日期-主题.md`（例如 `2026-11-20-第一次点灯.md`）
- 每天学完写一条，10~20 分钟，不要抄教程，写**自己的话 + 自己踩的坑**
- 模板见 [`_模板-每日笔记.md`](_模板-每日笔记.md)

## 为什么值得坚持写

1. **复习**：两周后你会忘掉 80%，笔记是你唯一的外挂大脑
2. **面试**：把"踩过什么坑、怎么定位的"讲成故事，比背八股强十倍
3. **证据**：招聘方翻你 GitHub 时，看的是你有没有工程习惯
4. **反推理解**：写不出来 = 没真懂，逼自己补
